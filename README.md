# School Desert Donor Map

Interactive tool for donors and policymakers to identify optimal school construction sites.

Covers 21 low- and middle-income countries. Sites are ranked by children brought within reach of a school.

**[Open the map →](https://lcrawfurd.github.io/school-deserts-map/)**

---
Based on: Crawfurd et al. (2025), *Measuring School Deserts*. Data sources: EMIS registries + WorldPop age-disaggregated grids.
